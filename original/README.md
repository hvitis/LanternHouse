# Reference images (not published)

Put your reference photos here: the house you are modelling, a kit you are comparing against, details you want to match.

Everything in this folder except this file is git-ignored. Reference photos are usually other people's copyrighted images, so they stay on your machine. The build never reads them. They only guide edits to `source/config.json`, `source/model.py` and `source/architecture.py`.

The design in this repository was drawn from the classic blue round tower with a red cone roof, a side veranda under a red hipped roof, a gabled entrance canopy, an attic dormer and a stone plinth.
